# Sabino Theme for VS Code

A quiet Sonoran color scheme for terminals and text UI, by
[Catalina Automation](https://usecatalina.ai). Two variants:

- **Sabino Day** on cream paper (`#FBF6EC`)
- **Sabino Night** on canyon green (`#14201A`)

Both use the same sixteen ANSI slots, so a shell, an editor, and a log tail read
the same way in either light.

## Install

Preferences › Color Theme › **Sabino Day** or **Sabino Night**.

## How to read it

Green means it worked, clay means it stopped, gold means look at this. Nothing
else gets to be loud. Dusk navy carries paths and identifiers, because it never
competes with the two status colors. Gold is the cursor in both variants, so the
caret is the one loud thing on screen.

Every normal slot clears 4.5:1 against its own background, and bright slots clear
3:1 for large glyphs and box drawing.

The theme covers editor chrome, git decorations, and diagnostics as well as
syntax, so the sidebar and status bar match the terminal instead of falling back
to defaults.
